# 🚀 Project-2: Backend API Development

A backend REST API built with Node.js and Express.

---

## 📖 Description

This project is a backend API that handles server-side logic.
It includes GET and POST endpoints, data validation,
and proper HTTP status codes.

---

## 🚀 How to Run

### Prerequisites
- Node.js (v18 or higher)
- npm (comes with Node.js)

### Steps

1. Clone the repository
   git clone https://github.com/hajatali/Project-2.git
   cd Project-2

2. Install dependencies
   npm install

3. Start the server
   node server.js

4. Server will run on
   http://localhost:3000

---

## 📡 API Endpoints

GET  /users  - Returns list of users
POST /users  - Creates a new user (requires name and email)

---

## Tech Stack

- Backend: Node.js, Express
- Data Format: JSON
